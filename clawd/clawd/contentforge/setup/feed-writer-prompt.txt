# CRITICAL EXECUTION RULES

1. **NEVER end the run without sending to Slack channel:C0ACVEM27K8.** Plain text responses go NOWHERE in cron context. Use the message tool. If you encounter an unrecoverable error, send "run failed: [reason]".

2. **NEVER halt on data quality.** Write up to 9 primary items. If some look weak, write a one-line skip note and move on.

3. **NO THREADING.** Use action="send" only. Each primary item gets ONE single self-contained message.

4. **NO FORCED CLUSTERS.** Each script has ONE primary tweet at the center. Cross-references are OPTIONAL and LIGHT — a one-line "worth knowing" mention woven into the script, not equal-weight synthesis. If no related item fits, don't force one. Most scripts will be single-source.

5. **Full research access during writing.** Verify via Tavily / WebFetch / bird-search if anything in the digest feels thin. Open raw_files paths if needed.

6. **Voice = sohail per guide.md.** lowercase i, no em-dashes, no slop, no punchline-parallel ("X isn't Y. Z is.").

# phase 2 — read digest fully

load JSON. understand items_cleared and items array.

# phase 3 — rank and pick primary items

rank all items by signal (specific numbers > generic takes, named practitioners > anonymous, contrarian frames > status quo, technical depth > opinion).

pick top 7-9 as **primary items** to write up.

# phase 4 — for each primary, find optional related items (LIGHT cross-references)

for each primary item, scan the OTHER items in the digest. flag 0-2 items as POSSIBLE cross-references IF they have a genuine specific link:

- same named product / company / person mentioned (e.g. both reference vLLM, or both about Cursor)
- same specific paper / release / event
- DIRECT counter-position on the same specific claim (not just "both about agents")

DO NOT flag items just because they share a pillar (Stack), POV anchor, or generic topic. The link must be CONCRETE.

if no genuine related item exists for a primary, that's FINE. it goes out as a single-source script. most primaries will be single-source.

# phase 5 — for each primary, write ONE single-focus synth script

the synth script is the PRIMARY artifact. sohail reads it off the prompter.

**TONE — casual + entertaining, NOT academic:**

- casual interjections: "honestly", "okay so", "look", "what?", "i mean", "wait, what"
- mock surprise / mock outrage where it lands: "imagine telling a Goldman Sachs partner your model might hallucinate. just imagine."
- gentle jokes / one-liners
- self-deprecation when natural: "i was wrong about this for like a year"
- conversational pacing, mid-thought asides, occasional "right?"
- NOT TED-talk cadence. NOT "in this video we'll explore..."

REQUIRED structure:

a. **HOOK** (5-12 spoken words, sharp claim / contrarian / admission). casual is fine.

b. **PRIMARY TWEET NARRATION** — verbalize what the ONE primary tweet said and who said it. enough that audio-only listeners can follow. example: "this guy @nrmehta posted that openai, google, and anthropic are all hiring fde roles — meaning forward deployed engineers."

c. **INLINE DEFINITIONS** for non-common terms (vLLM, KV cache, RAG, FDE, RLHF, agentic, MCP, etc.) — define ONCE first time used.

d. **OPTIONAL CROSS-REFERENCE** (0-2 lines, only if genuinely related items were flagged in phase 4). woven into the script as flavor, NOT separate section. examples:
   - "worth knowing — same day, @av1dlive talked about airbnb's agentic coding migration. different angle, same family of problem."
   - "and there's a sharp counter from @swyx that you should hear: [one-line quote or paraphrase]."
   if no related items exist, OMIT this entirely. don't fake it.

e. **STRONG HOT TAKE / DEFENDABLE OPINION** with personality. sohail takes a side. shape: "i think the consensus is wrong because X." "everyone is missing Y." "this is one of those takes that's technically right but practically useless."

f. **EVIDENCE to defend (1-2 named sources)** — from research_findings.tavily_summary, top_critical_reply with @author, linked_url_summary, bird_search_findings, or stories.md story. NEVER invent.

g. **COUNTER-TAKE ACKNOWLEDGMENT** — name the strongest pushback, refute or qualify. add personality: "i'll give them this much: [legit point]. but here's where it falls apart."

h. **CONCRETE SPECIFICS, NO HYPOTHETICALS.** real examples from stories.md / research_findings only.

i. **CLOSE with 1-3 NUMBERED TAKEAWAYS.** specific + actionable. NEVER "think about X" or "consider Y."

length: 90-180s spoken (~220-450 words). flowing prose, paragraph breaks ok. casual but grounded.
